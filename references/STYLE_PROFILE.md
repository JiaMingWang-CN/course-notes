# 微课风格规划模板

> 本文件是设计建议，不代表已经观看或分析任何课程。仅在生成微课时读取。
> 将本课程记录保存到交付章节的 `references/STYLE_PROFILE.md`；不要把课程特定信息写回技能安装目录。

## 1. 证据与复用范围

每门课程只建立一次基础记录，章节可补充必要差异。最多选取 2–3 节代表课；不要逐节重复分析。

```markdown
# <课程名称> 微课风格记录
- 来源：<BV号/URL/本地资料>
- 适用范围：<课程/章节>
- 可用材料：<字幕/音频/实际观看的视频>
- 分析日期：<实际日期>
- 样本：<P、标题、时间范围；未采样则写未采样>
- 已观察到的特征：<附样本定位>
- 未核实项：<如配色、镜头、语速>
- 本次设计选择：<明确与原片观察区分>
```

| 可用资料 | 可以归纳 | 不可据此声称 |
|---|---|---|
| 仅字幕 | 知识组织、例题顺序、措辞 | 原片配色、镜头、音色、实测语速 |
| 音频 | 实际听到的节奏、停顿与发音 | 原片画面与布局 |
| 视频 | 实际观看片段内的视听特征 | 未观看部分或全课程一致性 |
| 无样本 | 下述默认设计建议 | 已完成抽样、讲师采用了这些风格 |

样本可按概念课、实现课、算法推演课挑选，但不得预填虚构 P 号或观察结论。既有记录只有在来源与范围一致时才能复用。

## 2. 教学结构

优先服务理解与复习，不使用“从不考证明”“必考”“10 秒必解”等未经证实的承诺。

建议安排：

1. **目标与条件**：说明要解决的问题、前置知识与适用范围。
2. **核心推演**：围绕一个代表例子展示状态变化；清楚标出变量和下标约定。
3. **易错反例**：展示失败条件及原因，不只闪烁警报。
4. **回顾与自检**：总结关键结论，给一道标注来源或“自编”的小题。

以 3–5 分钟为目标，根据实际口播字数、推演和停顿分配时长；不得把估算称为实测。复杂小节可拆成多个片段，不能删除保证结论成立的条件。

公式速记应同时保留通式、变量含义与边界。例如卡特兰数表只在题目满足相应计数模型时适用，不能脱离条件直接套值。

## 3. 制作文档一致性

| 资产 | 必要内容 |
|---|---|
| `BRIEF.md` | 学习目标、受众、来源、范围、不遗漏的事实 |
| `TREATMENT.md` | 设计选择、画面层次、主题、交互与降级方案 |
| `SCRIPT.md` | 可朗读台词、公式读法、必要停顿、画面提示 |
| `STORYBOARD.md` | 连续场景编号、预计起止时间、画面状态、对应台词 |

四份文档与笔记保持术语、例子、答案一致。预计总时长应与分镜合计一致；未实际播放时不得标为“音画同步已验证”。

本地生成器输出的是模板，不会自动读取风格记录。生成后需人工/主代理落实设计要求并修正失效的相对链接。

## 4. 固定视觉与交互规范

### 色彩：温和，但重点鲜明

- 唯一内置主题为 `calm_textbook`（温和教材），不提供换肤或其他风格。
- 暖白、浅灰绿用于大面积背景，减少纯白刺眼感；深墨绿承载标题、导航和播放控制。
- 琥珀色只用于易错提醒，不使用高饱和颜色争抢注意力。

### 排版：教材的严谨与数字界面的轻盈

- 中文标题清晰、有分量，正文舒展，辅助信息降低视觉权重。
- 数值、下标、章节时间和数据读数使用等宽字体，便于逐项对照。
- 小字号英文与章节编号只作为索引，不喧宾夺主。

### 组件：柔和边界，少量装饰

- 卡片使用适度圆角、细边框和轻浅底色，主要靠留白和对齐划分内容。
- 不使用厚重阴影、玻璃效果或复杂渐变；保持纸张般的安静感，但不刻意仿旧。

### 交互与音画同步

- 播放、暂停、跳转状态明确；显示时间采用等宽数字，避免抖动。
- “未访问、已访问、当前访问”同时用颜色、文字状态与数据读数区分，不能只依赖颜色。
- 课程播放和动手演示各自独立；按钮名称直接说明操作，不让用户猜测。
- 每段画面必须来自当前口播对应的笔记知识点。仅在沙盘模型经过本课内容建模时启用专用算法动画；否则使用知识点逐项状态演示，不用无关模板冒充。
- Fish Audio 使用真实音频时长驱动进度、字幕和画面；当前段自然结束后立即播放下一段，不用固定秒数等待或截断。
- Fish Audio 的可见字幕与表演文本分离。表演文本将内容拆成适合讲授的短句，并在局部加入方括号自然语言语气提示、独立 `[emphasis]` 和 `[pause]`；标签不得显示在字幕中。
- 默认教师表达曲线：导入温暖自信；概念解释平静清楚；关键条件适当放慢并强调；易错提醒压低、坚定；总结温暖鼓励。每句只设一个主要情绪，避免夸张表演和标签堆叠。
- 有实际课程音频时，只学习可观察的节奏、停顿、设问和转折习惯，并记录样本位置；仅有字幕时不得声称模仿原讲师语气，也不得擅自克隆声音。
- 按钮可经键盘操作，并有可见焦点；窄屏文字可换行；尊重减少动画偏好。
- 语音不可用时仍能阅读完整台词；外部资源依赖与兼容性以实际检查结果为准。

以上是制作目标；交付时仍须按实际结果记录是否完成浏览器审查。

## 5. 交付状态

记录实际完成情况，避免把计划当结果：

- 内容：已核对 / 待核实（列出项目）。
- 制作文档：已生成 / 缺失。
- HTML：已生成 / 未生成 / 存在已知限制。
- 浏览器审查：通过 / 失败 / 未运行（原因）。
- 视频文件：只有实际生成后才列出；HTML 与分镜不等于 MP4。

用户明确要求不测试时，停止于静态内容核对，不运行浏览器或其他测试，并标记“未运行”。
